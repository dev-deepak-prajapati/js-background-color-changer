# js-background-color-changer - Background Color Changer 🎨

A lightweight, responsive web application built with **Vanilla JavaScript**, **HTML5**, and **CSS3** that lets users dynamic change background colors. Users can input their own colors (Names, Hex codes, RGB, HSL) or cycle through a curated array of beautiful pre-defined colors.

## 🚀 Features

- **Custom User Input:** Type any valid CSS color specifier (like `red`, `#d9fce4`, or `rgb(83, 141, 2)`) to update the background instantly.
- **Random Preset Generator:** Tap the "Random Color" button to cycle through 20 custom curated aesthetic color options.
- **Live Label Tracking:** Displays the active background color formatting string in real-time.
- **Fully Responsive Architecture:** Adapts smoothly across mobile, tablet, and desktop display viewports.

## 🛠️ Tech Stack

- **Markup:** HTML5
- **Styling:** CSS3 (Flexbox, custom shadows, responsive layout)
- **Logic:** JavaScript (ES6, DOM Manipulation, Event Listeners)

## ⚙️ How to Setup Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/dev-deepak-prajapati/js-background-color-changer.git
   ```

2. **Navigate into the directory:**
   ```bash
   cd js-background-color-changer
   ```

3. **Open the project:**
   Simply double-click `index.html` or run it using an extension like **Live Server** in VS Code.
